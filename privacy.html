Privacy policy

short-videos uploader is a private tool used only by its owner to upload their own videos to their own YouTube channel.

What it accesses

With the owner's permission it uses the YouTube Data API scope youtube.upload, which only allows uploading videos. It does not read, store or share any other YouTube or Google account data.

What it stores

The authorization token is stored as an encrypted secret in the owner's private GitHub repository and is used only to upload videos. No data about other people is collected, sold or shared.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
